# 🚀 Cloud Runner — DTrongVIP Autonomous Background Engine

Hệ thống điều phối tác vụ và chạy bot/worker ngầm trên nền tảng Cloud 24/7 (0đ chi phí):
- **Hạ tầng**: GitHub Actions Runners (Ubuntu 24.04, 2-core vCPU, 7 GB RAM, 14 GB SSD) & Cloud Containers.
- **Mục tiêu**: Giải phóng 100% RAM và CPU cho laptop cá nhân, di chuyển toàn bộ các worker ngầm lên cloud chạy độc lập.
- **Điều khiển**: Quản trị trực tiếp từ xa thông qua GitHub CLI (`gh workflow run`) hoặc REST API.
